This folder contains the R and Bash scripts used for metagenomic processing, environmental data preparation, and statistical analyses. Scripts are numbered according to their general workflow order.

Run Section 1 of `1. NEON_metagenomic_environmental_data.R` to generate the sequencing URLs required for `2. Metagenomic_analysis.sh`. Complete the remaining sections of Script 1 to prepare the environmental data and Script 2 to generate the metagenomic data before running `3. Biofilm_gene_analysis.R` for statistical analyses.
