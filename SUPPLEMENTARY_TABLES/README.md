This folder contains the supplementary tables associated with the manuscript.

- `TableS1.xlsx`: Sample metadata and multi-year summaries of daily environmental conditions at each site from 2016 to 2020.
- `TableS2.xlsx`: Summary statistics at each step of the metagenomic processing pipeline.
- `TableS3.xlsx`: Functional annotation of CDSs predicted in each sample. The original dataset is available in the `DATABASES_AND_METADATA` folder as `all_samples.emapper.annotations.tsv`.
- `TableS4.xlsx`: Raw gene abundance per sample. The original dataset is available in the `DATABASES_AND_METADATA` folder as `all_genes_long_all_samples.tsv`.
- `TableS5.xlsx`: Database of KOs associated with bacterial biofilm-related pathways.
- `TableS6.xlsx`: Normalized abundance of biofilm-associated genes by sample, with KO and pathway assignments. The original dataset is available in the `DATABASES_AND_METADATA` folder as `TableS6_biofilm_normalized_counts.csv`.

Due to GitHub file size limitations, the following files are stored externally in Google Drive:

- `TableS3.xlsx`
- `TableS4.xlsx`
- `TableS6.xlsx`

The files can be accessed through [Google Drive](https://drive.google.com/drive/folders/1VcSJDCbtFUTi3diNNcIN10MFbYTHOCWB?usp=sharing).
