This folder contains the databases and metadata generated by or used as inputs for the scripts.

- `metagenome_urls_2017.txt`: URLs for downloading the 119 selected paired-end metagenomes (238 URLs). Generated using `1. NEON_metagenomic_environmental_data.R`.
- `TableS2_summary_pipeline_stats.csv`: Summary statistics at each step of the metagenomic processing pipeline. Generated using the summaries in `2. Metagenomic_analysis.sh`. This file is the CSV version of `TableS2.xlsx`.
- `all_samples.emapper.annotations.tsv`: Functional annotations of predicted coding sequences (CDSs) across all metagenomic samples. Generated using `2. Metagenomic_analysis.sh`. This file is the TSV version of `TableS3.xlsx`.
- `all_genes_long_all_samples.tsv`: Raw read counts assigned to all predicted CDSs (biofilm-associated and non-biofilm-associated) across all metagenomic samples. Generated using `2. Metagenomic_analysis.sh`. This file is the TSV version in long format of `TableS4.xlsx`.
- `coord_sites.csv`: NEON site metadata and coordinates.
- `TableS1_metadata2017.csv`: Sample metadata and multi-year summaries of daily environmental conditions at each site from 2016 to 2020. Generated using `1. NEON_metagenomic_environmental_data.R`. This file is the CSV version of `TableS1.xlsx`.
- `TableS5_KO_list_pathways.csv`: Database of KOs associated with bacterial biofilm-related pathways from Thorpe et al. (2025). This file is the CSV version of `TableS5.xlsx`.
- `TableS6_biofilm_normalized_counts.csv`: Normalized abundance of biofilm-associated genes by sample, with KO and pathway assignments. Generated using `3. Biofilm_gene_analysis.R`. This file is the CSV version of `TableS6.xlsx`.

Due to GitHub file size limitations, the following files are stored externally in Google Drive:

- `all_samples.emapper.annotations.tsv`
- `all_genes_long_all_samples.tsv`
- `TableS6_biofilm_normalized_counts.csv`

The files can be accessed through [Google Drive](https://drive.google.com/drive/folders/1nsWLMJEL02yFk7u8a1kqxuETyxWJE7E8?usp=sharing).

Download these files before running the scripts.
